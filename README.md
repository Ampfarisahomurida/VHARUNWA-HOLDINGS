# Vharunwa Holdings website

This is a static website ready to deploy on Render. All project photos are stored in `images/` and are displayed in the Home-page **Our Work** section and in the Gallery.

## Deploy on Render

1. Upload this project to a GitHub repository.
2. In Render, select **New** → **Blueprint**.
3. Connect the GitHub repository and select the `render.yaml` file.
4. Render will create a static website. Click **Apply** and then use the provided public URL.

No build command or environment variables are required.
